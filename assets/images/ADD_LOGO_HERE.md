# Как добавить логотип на Splash Screen

## Текущее состояние
✅ Splash screen настроен с фирменным оранжевым цветом (#FF6B35)
⏳ Логотип пока не добавлен (показывается только цвет)

## Быстрая инструкция

### Шаг 1: Подготовьте логотип
- Формат: PNG с прозрачным фоном
- Размер: 512x512px (рекомендуется)
- Цвет: Белый или светлый (для контраста на оранжевом)

### Шаг 2: Добавьте файл
Поместите логотип в: `assets/images/logo.png`

### Шаг 3: Раскомментируйте в pubspec.yaml
Откройте `pubspec.yaml` и найдите секцию `flutter_native_splash`:

```yaml
flutter_native_splash:
  color: "#FF6B35"
  image: assets/images/logo.png  # Раскомментируйте эту строку
  
  android_12:
    color: "#FF6B35"
    image: assets/images/logo.png  # И эту
```

### Шаг 4: Регенерируйте splash screen
```bash
dart run flutter_native_splash:create
```

### Шаг 5: Проверьте результат
```bash
flutter clean
flutter run
```

Закройте приложение полностью и запустите снова - вы увидите логотип на оранжевом фоне!

---

## Альтернатива: Использовать текст вместо логотипа

Если у вас нет готового логотипа, можно создать простой текстовый:
1. Используйте онлайн-редактор (Canva, Figma)
2. Создайте 512x512px изображение
3. Добавьте текст "Добро.КГ" белым цветом
4. Экспортируйте как PNG с прозрачным фоном
