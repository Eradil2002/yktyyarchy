# Ыктыярчы.КГ (Ыктыярчы.kg) - Платформа Волонтеров Кыргызстана 🌟

**Ыктыярчы.KG** — это мобильное приложение и масштабируемая платформа, объединяющая волонтеров и социальные организации (НКО). С помощью этого инструмента любой желающий может найти мероприятия по душе, проявить себя, получить грамоты и реальный волонтерский стаж, а НКО — найти надежных помощников.

Платформа состоит из мощного **Backend** на Django REST Framework и кроссплатформенного **Frontend** мобильного приложения на Flutter.

## ✨ Основные возможности (Features)

### Для Волонтеров
- 🗺️ **Карта добрых дел:** Интерактивный поиск мероприятий и задач рядом с вами.
- 🏆 **Геймификация и Достижения:** Зарабатывайте стаж, получайте 3D-награды (медали) и повышайте свой рейтинг.
- 💡 **Личные инициативы:** Предлагайте свои социальные проекты и собирайте команду.
- 🔔 **Уведомления:** Мгновенные пуш-уведомления об изменении статуса регистраций и отзывов.

### Для НКО (Организаций)
- 📅 **Управление мероприятиями:** Публикация событий (онлайн/оффлайн) с детальным описанием и загрузкой обложек.
- 👥 **Радар талантов:** Поиск волонтеров по специфическим навыкам (IT, медицина, экология).
- 📝 **Отзывы и Оценки:** Возможность оценивать волонтеров после мероприятия, формируя их социальный рейтинг.

### UX/UI
- 🎨 **Брендированный Splash Screen:** Фирменный оранжевый экран загрузки вместо стандартного белого.
- 📱 **Адаптивный дизайн:** Поддержка Android 12+ и iOS с нативными splash screens.

## 🛠 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/Marlen2006/Volunteering.git
cd Volunteering
```

### 2. Запуск Backend (Django API)

Бэкенд отвечает за базу данных и логику работы. Он должен быть запущен, чтобы приложение получало данные.

1. Откройте терминал и перейдите в папку backend:
   ```bash
   cd backend
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Linux/Mac:
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте базу данных и примените конфигурации (.env):
   Убедитесь, что внутри папки `backend/` есть файл `.env` (если его нет - скопируйте `.env.example`).
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```
5. **Наполнение тестовыми данными (Важно!)**
   Команда ниже создаст готовых НКО, мероприятия, обложки и волонтеров для теста:
   ```bash
   python manage.py seed_db
   ```
6. Запустите локальный сервер:
   ```bash
   python manage.py runserver
   ```
*Сервер API запустится по адресу: `http://localhost:8000`*

### 3. Запуск Frontend (Flutter App)

1. Откройте новую вкладку терминала и оставайтесь в корне проекта (или перейдите в `lib`).
2. Загрузите зависимости:
   ```bash
   flutter pub get
   ```
3. (Опционально) Настройте Firebase: если вы планируете тестировать PUSH-уведомления, добавьте актуальный `google-services.json` в `android/app/` (для Android) или `GoogleService-Info.plist` в `ios/Runner/` (для iOS).
   
   **Важно:** Приложение работает и без Firebase! Если конфигурационные файлы отсутствуют, приложение запустится в режиме без push-уведомлений. В консоли вы увидите:
   ```
   ⚠ Firebase initialization failed
   ⚠ App will run without push notifications
   ```
   Все остальные функции (карта, события, профиль, достижения) будут работать полностью.

4. Запустите приложение на устройстве или эмуляторе:

   **Для Android эмулятора (по умолчанию):**
   ```bash
   flutter run
   ```

   **Для iOS симулятора:**
   ```bash
   flutter run --dart-define=API_URL=http://localhost:8000/api
   ```

   **Для реального устройства (замените IP на адрес вашего компьютера):**
   ```bash
   flutter run --dart-define=API_URL=http://192.168.0.102:8000/api
   ```

   **Для production сборки:**
   ```bash
   flutter run --release --dart-define=API_URL=https://api.yktyyarchy.kg/api
   ```

*(Примечание: приложение по умолчанию обращается к API по адресу `http://10.0.2.2:8000/api` для эмуляторов Android. Для других окружений используйте флаг `--dart-define=API_URL=<ваш_url>`).*

## 📦 Сборка Release версии

Для публикации в Google Play Store необходимо настроить подписание приложения:

1. **Создайте upload keystore** (один раз):
   ```bash
   keytool -genkey -v -keystore android/upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```

2. **Создайте файл `android/key.properties`**:
   ```properties
   storePassword=ВАШ_ПАРОЛЬ
   keyPassword=ВАШ_ПАРОЛЬ_КЛЮЧА
   keyAlias=upload
   storeFile=../upload-keystore.jks
   ```

3. **Соберите release версию**:
   ```bash
   # APK для прямой установки
   flutter build apk --release --dart-define=API_URL=https://api.yktyyarchy.kg/api
   
   # AAB для Google Play Store (рекомендуется)
   flutter build appbundle --release --dart-define=API_URL=https://api.yktyyarchy.kg/api
   ```

**Подробная инструкция:** См. [RELEASE_SIGNING.md](RELEASE_SIGNING.md)

## 🏗 Архитектура

- **Flutter / Dart:** Использование паттерна Provider для управления состоянием, Dio для сетевых запросов.
- **Django / Python:** Использование DRF (Django REST Framework), JWT-авторизация (Simple JWT).
- **СУБД:** SQLite для локального тестирования, полностью готово для миграции на PostgreSQL в продакшен.

*Разработано для укрепления волонтерской среды и социального сектора.* 🇰🇬
